A fast, client-side password generator that creates *unbreakable passwords using real cryptographic randomness* (crypto.getRandomValues()).  
No data ever leaves your browser · 100% private · No tracking · No servers · Open source

### 🛡️ Why This Generator Is Actually Secure
Most online password generators use Math.random() → *weak and predictable*.  
This tool uses *Web Crypto API* (crypto.getRandomValues()), the same standard used by banks, Bitcoin wallets, and HTTPS.  
The generated passwords have extremely high entropy and can resist even nation-state level brute-force attacks.
